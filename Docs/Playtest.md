# MVP 플레이테스트 기록

## 조율과 계측 로그

다이브 중 `F1`을 눌러 전투 조율 창을 열고 값을 바꾼 뒤 **저장**을 누른다. 설정은 플레이어 데이터의 `tuning/combat.json`에 JSON으로 저장되며, 새 설정을 적용하면 별도의 계측 세션이 시작된다.

각 차지 해제, 검기 종료, 다이브 종료 시 `telemetry/combat-telemetry.csv`에 누적 스냅샷이 기록된다. 기본 위치는 Unity의 `Application.persistentDataPath` 아래다. 재현 가능한 테스트에서는 실행 전에 별도 경로를 지정한다.

```powershell
$env:HUNTERWIDOW_TELEMETRY_PATH = "$PWD\Logs\combat-telemetry.csv"
& .\Builds\HunterWidowMvp.exe
```

CSV의 같은 `sessionId`에서 `dive_finished` 행은 그 다이브의 최종 합계다. `sweetSpotRatio`가 숙련 후 0.60–0.75인지, `roundTripHitRate`와 `forwardHitRate`가 기대한 손맛을 뒷받침하는지 확인한다. `dive_started`와 `dive_finished`의 `timestampUtc` 차이로 연속 전투 시간이 남는다.

## 사람이 확인할 게이트

자동 검증은 규칙과 저장만 증명한다. Gate 1은 조율을 멈춘 뒤 10분 연속 전투, CSV 성공률, 설명 없는 외부 3명 5분 체험(2명 이상이 “한 번 더”)을 기록해 통과시킨다. Gate 2는 서로 다른 조건에서 다이브–귀환–조제 루프를 5회 반복하고, 3회째 반복에도 지루하지 않은지 플레이어 의견으로 판단한다.
